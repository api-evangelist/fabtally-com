FabTally provides a REST and MCP API that delivers 3D‑printing quotes, G‑code generation, and printability checks using a real slicer backend. Users can submit 3D models and receive estimated print time, filament usage, layer count, dimensions, a fits‑on‑bed verification, and pricing. The service supports 13 printer models and 12 material types, offering free access for individuals and a pay‑per‑call model in USDC for agents. The API is documented via an OpenAPI 3.1 specification available at /openapi.json.

**Areas:** Company · 3D-printing · Slicing · Quotes · API · Manufacturing
